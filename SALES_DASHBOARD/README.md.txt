# Sales Performance Dashboard

## Project Objective
This project analyzes retail business sales performance using Power BI to identify revenue trends, profitable categories, top-performing products, and regional performance.

## Tools Used
- Power BI
- Superstore Sales Dataset

## Key Performance Indicators (KPIs)
- Total Revenue
- Total Profit
- Total Orders
- Profit Margin %

## Analysis Performed
- Revenue Trend Analysis
- Regional Performance Analysis
- Product Performance Analysis
- Category Profitability Analysis
- Interactive Filtering using Slicers

## Key Business Insights
- Technology category drives strong revenue performance.
- Regional sales and profitability vary significantly.
- Top products contribute disproportionately to total sales.
- Profitability does not always match revenue.

## Recommendations
- Increase focus on high-performing categories.
- Improve low-performing regions.
- Review pricing and discount strategy to improve profitability.
